无论是夯实计算机基础、日常代码开发，还是探索前沿 AI——Linux 都是理工科同学绕不开的技术底座，而 AI Agent（智能体） 则是正在重塑人机交互的下一代生产力工具。

Xflops × SJTUG 专为大一新生量身打造！无论你此前是否有编程经验，我们都将在现场手把手带你跨过技术门槛，轻松开启你的 CS 之旅。

活动亮点

  • 认识与配置 Linux：告别报错焦虑，现场带你搞定环境，解锁命令行操作
  • Agent 入门与实操：拒绝纸上谈兵，带你动手跑通属于你的第一个 AI 智能体任务

完全零基础友好，从第一次敲下回车开始，带你真正踏入 CS 的大门！

注意事项与提前准备

API Token 准备：实操必备。如无自有 Token，可登录“交我办” “致远一号”AI模型API申请 免费获取。

Linux 环境准备：现场会带大家安装（不要求提前装好，但为防网络拥堵请提前下载）。若电脑无 Linux 环境，请先安装虚拟机软件（VMware 或 VirtualBox），并根据机型在以下两项中二选一下载：
选项一：Ubuntu 24.04 镜像
Windows / x64 机器：https://mirror.sjtu.edu.cn/ubuntu-releases/24.04/ubuntu-24.04.4-desktop-amd64.iso
Mac / arm 机器：https://mirror.sjtu.edu.cn/ubuntu-releases/24.04/ubuntu-24.04.4-desktop-amd64.iso
选项二：预配置 vmdk 压缩包（HPC 入门指南提供，Mac 不可用）：https://xflops.sjtu.edu.cn/big_assets/xflops_standard_env.vmdk.zip
